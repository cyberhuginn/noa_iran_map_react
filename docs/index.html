Noa Iran Map React

The ultimate interactive map of Iran for React and Next.js applications

About

Noa Iran Map React is a highly customizable and interactive map of Iran designed specifically for React and Next.js applications.

With full TypeScript support, dynamic province highlighting, and a lightweight architecture, it is ideal for dashboards, analytics platforms, and data-driven applications.

Whether you need to visualize sales data, user distribution, regional statistics, or any province-based information, this package provides a simple and powerful solution.

Features

  • Dynamic Province Coloring: Highlight provinces using province codes and custom values.
  • TypeScript Ready: Full TypeScript support with strong typing and better developer experience.
  • Next.js Friendly: Optimized for modern React and Next.js applications.
  • Interactive: Supports tooltips and dynamic data updates.
  • Lightweight: No unnecessary dependencies.
  • Highly Customizable: Easily customize colors and behavior using props.

Installation

npm install noa-iran-map-react

Usage Example

import React from 'react';
import IranMap from 'noa-iran-map-react';

export default function Home() {
    const data = {
        "IR-32": 100, // Alborz
        "IR-15": 200, // Kerman
        "IR-04": 250, // Fars
    };

    return (
        <IranMap data={data} />
    );
}

Props

Prop Type Default Description
color string #FF5733 Fill color for provinces that contain data.
backgroundColor string #E0E0E0 Default color for provinces without data.
tooltipLabel (code: string) => string undefined Function used to generate tooltip labels.
data Record<string, number> {} Province codes mapped to numeric values.
