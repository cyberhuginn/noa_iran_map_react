Noa Iran Map React

نقشه تعاملی و قابل شخصی‌سازی ایران برای React و Next.js

درباره پروژه

Noa Iran Map React یک کتابخانه متن‌باز برای نمایش نقشه تعاملی ایران در پروژه‌های React و Next.js است.

این کتابخانه با پشتیبانی کامل از TypeScript امکان رنگ‌آمیزی استان‌ها، نمایش داده‌های آماری و ساخت داشبوردهای حرفه‌ای را فراهم می‌کند.

اگر قصد نمایش آمار فروش، کاربران، سفارشات یا هر نوع داده جغرافیایی در ایران را دارید، این کتابخانه راهکاری سبک و ساده در اختیار شما قرار می‌دهد.

ویژگی‌ها

  • رنگ‌آمیزی پویا استان‌ها: نمایش داده‌ها روی استان‌های مختلف ایران.
  • پشتیبانی کامل از TypeScript: توسعه آسان‌تر با تایپ‌های دقیق.
  • سازگار با Next.js: مناسب برای SSR و برنامه‌های مدرن React.
  • کاملاً تعاملی: پشتیبانی از Tooltip و بروزرسانی لحظه‌ای داده‌ها.
  • سبک و سریع: بدون وابستگی‌های سنگین.
  • سفارشی‌سازی آسان: امکان تغییر رنگ‌ها و رفتار نقشه از طریق Props.

نصب

npm install noa-iran-map-react

نمونه استفاده

import React from 'react';
import IranMap from 'noa-iran-map-react';

export default function Home() {
    const data = {
        "IR-32": 100, // Alborz
        "IR-15": 200, // Kerman
        "IR-04": 250, // Fars
    };

    return (
        <IranMap data={data} />
    );
}

پراپرتی‌ها (Props)

نام نوع پیش‌فرض توضیحات
color string #FF5733 رنگ استان‌هایی که داده دارند.
backgroundColor string #E0E0E0 رنگ پیش‌فرض استان‌های بدون داده.
tooltipLabel (code: string) => string undefined متن Tooltip هنگام قرار گرفتن ماوس روی استان‌ها.
data Record<string, number> {} داده‌های مربوط به هر استان.
